# Regla de Proyecto: Portfolio Comercial de MVPs

Al iniciar cualquier sesión o recibir una nueva instrucción en este proyecto:
1. Lee obligatoriamente:
   - `PROMPT_MAESTRO.md`
   - `AI_RULES.md`
   - `README.md`
   - `PROJECT_STATUS.md`
2. Contrasta el estado declarado con el workspace real.
3. No reinicies fases completadas ni agregues funciones fuera de alcance.
4. Antes de cerrar tu intervención, ejecuta los comandos de verificación aplicables y actualiza `PROJECT_STATUS.md` con evidencias reales.
